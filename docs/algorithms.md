# Алгоритмы стеганографии

## LSB-метод (Least Significant Bit)

### Внедрение
1. Читаем BMP-файл, получаем массив пикселей (BGR-байты)
2. Формируем payload: `[4 б. длины][4 б. CRC32][данные сообщения]`
3. Для каждого байта payload:
   - Разбиваем на chunks по N бит (N = 1, 2 или 4)
   - Заменяем N младших бит очередного пикселя каждым chunk
4. Сохраняем изменённый BMP

### Извлечение
1. Читаем BMP-файл, получаем массив пикселей
2. Извлекаем N младших бит из каждого пикселя, собираем байты
3. Читаем 4 байта → длина сообщения
4. Читаем 4 байта → CRC32
5. Читаем `длина` байт → данные
6. Вычисляем CRC32 от (длина + данные), сравниваем с сохранённым
7. Если CRC32 не совпадает — данные повреждены

### Ёмкость
```
capacity = (ширина × высота × 3 × lsbBits) / 8 - 8
```
(8 байт overhead: 4 на длину, 4 на CRC32)

## Контейнерный метод

### Внедрение
1. Читаем BMP-файл целиком
2. Если в нём уже есть контейнер — отрезаем его
3. Дописываем в конец:
   - Маркер `STEG_CONTAINER`
   - 8 байт размера архива (little-endian)
   - Данные архива

### Извлечение
1. Ищем маркер `STEG_CONTAINER` с конца файла
2. Читаем 8 байт размера
3. Проверяем, что `позиция_маркера + длина_маркера + 8 + размер_архива == размер_файла`
4. Извлекаем данные архива

## Метрики качества

### MSE (Mean Squared Error)
```
MSE = (1/N) × Σ(original[i] - stego[i])²
```

### PSNR (Peak Signal-to-Noise Ratio)
```
PSNR = 10 × log₁₀(255² / MSE)   [дБ]
```

| PSNR | Качество |
|------|----------|
| > 40 дБ | Изменения незаметны |
| 30–40 дБ | Слабозаметны |
| < 30 дБ | Заметные искажения |
