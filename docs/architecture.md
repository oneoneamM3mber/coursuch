# Архитектура StegoLab

## Общая структура

Приложение построено по многослойной архитектуре:

```
┌─────────────────────────────────────┐
│          MainWindow (UI)            │  ← Qt Widgets (Facade)
├─────────────────────────────────────┤
│        Steganography (core)         │  ← Алгоритмы (Strategy)
├─────────────────────────────────────┤
│          Database (storage)         │  ← SQLite (Repository)
└─────────────────────────────────────┘
```

## Компоненты

### Steganography (`src/steganography.cpp`)
Реализует два метода стеганографии:

- **LSB (Least Significant Bit)** — замена N младших бит пикселей битами сообщения
- **Контейнерный метод** — дописывание архива в конец BMP-файла

Формат LSB-внедрения:
```
[4 байта: длина сообщения (big-endian)]
[4 байта: CRC32 (длина + данные)]
[N байт: сообщение]
```

CRC32 обеспечивает контроль целостности: при изменении хотя бы 1 бита
изображения после внедрения CRC32 не совпадает, и пользователь видит
предупреждение.

### Database (`src/database.cpp`)
Хранит историю операций в SQLite (`stego_history.db`):
- информация об изображении (разрешение, глубина цвета)
- метрики качества (PSNR, MSE)
- метод внедрения
- временная метка

### MainWindow (`src/mainwindow.cpp`)
UI на Qt Widgets, 4 вкладки:
1. **Внедрение (LSB)** — выбор изображения, ввод сообщения, внедрение
2. **Извлечение (LSB)** — извлечение сообщения с проверкой CRC32
3. **Контейнерный метод** — внедрение/извлечение архивов
4. **История** — просмотр и удаление записей БД

## Паттерны проектирования

| Паттерн | Применение |
|---------|-----------|
| **Strategy** | LSB-1/2/4 и Container — разные стратегии, объединённые общим интерфейсом |
| **Facade** | MainWindow предоставляет единый интерфейс для всех операций |
| **Repository** | Database инкапсулирует доступ к SQLite |
| **Template Method** | embedLSB/extractLSB — общий алгоритм (загрузка → обработка → сохранение) |
